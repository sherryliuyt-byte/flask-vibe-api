# 前端串接

本文件依 [交換格式.md](./交換格式.md) 整理端點與欄位，並以 [資料表設計.md](./資料表設計.md) 核對可空性及約束。此文件只描述兩份規格已提供的內容；沒有定義的端點或欄位不作推測。

## 共通規則

- 每個回應外層固定包含 `code`、`message`、`data` 三個鍵；`code` 與 HTTP 狀態碼相同。
- 成功狀態碼：`200`（查詢、更新或處理成功；無資料清單為 `data: []`）、`201`（新增成功）。
- 失敗狀態碼：`400`（請求或資料規則不符）、`404`（路徑資料不存在）、`405`（不支援的方法）、`500`（資料庫操作失敗）。失敗時 `data` 為 `null`，`message` 使用固定人話句子。
- 客戶端不送 `id`、`created_at`、`updated_at`；這些欄位由伺服器或資料庫管理。範例中的 ID 僅為數字示意，實際 ID 以回應為準。
- 日期使用 `YYYY-MM-DD` 字串；月合計月份使用 `YYYY-MM`。
- 金額使用 JSON 數字，不使用帶引號的數字字串。數量、價格、比例及匯率也以 JSON 數字傳送。
- 可空欄位在回應中保留欄位並以 `null` 表示，不以省略欄位代替。
- 除另有註明外，範例略去非必要欄位；欄位完整清單列於各端點的 `data` 說明。

## 錯誤句子表

| `error_code` | HTTP 狀態 | 客戶端句子 |
|---|---:|---|
| `conflict.unique_name` | 400 | 帳戶名稱已存在。 |
| 交換格式未列 | 404 | 找不到這個帳戶。 |

交換格式僅列出 `conflict.unique_name` 這個 `error_code`；404 範例有客戶端句子，但沒有對應的 `error_code`。未列出的錯誤代碼或固定句子不在此推定。交換格式沒有 `upstream.twse`，因此沒有可列入的證交所錯誤碼。若將來交換格式加入該代碼，客戶端句子應為「證交所目前沒有回應」。

回應 JSON 不包含資料表名、約束名、SQL、SQLSTATE、例外類別或堆疊。這些資訊不提供給客戶端。

## 端點

### 健康檢查

交換格式沒有定義健康檢查端點的 HTTP 方法、路徑、請求或成功回應欄位；不在此推定。

### 帳戶

#### `GET /api/accounts`

- 查詢參數：無。
- 請求欄位：無。
- 成功時 `data`：帳戶物件陣列；每項包含 `id`、`name`、`kind`、`currency`、`opening_balance`、`statement_day`、`payment_day`、`created_at`、`updated_at`。
- 最小範例：`{"code":200,"message":"查詢成功。","data":[{"id":1,"name":"現金","kind":"cash","currency":"TWD","opening_balance":0,"statement_day":null,"payment_day":null}]}`

#### `POST /api/accounts`

- 查詢參數：無。
- 請求欄位：`name`、`kind` 必填；`currency`、`opening_balance` 可省略；`statement_day`、`payment_day` 可為 `null`。
- 成功時 `data`：`id`、`name`、`kind`、`currency`、`opening_balance`、`statement_day`、`payment_day`、`created_at`、`updated_at`。
- 最小範例：`{"code":201,"message":"帳戶新增成功。","data":{"id":1,"name":"現金","kind":"cash","currency":"TWD","opening_balance":0,"statement_day":null,"payment_day":null}}`

#### `GET /api/accounts/{account_id}`

- 查詢參數：無。
- 請求欄位：路徑參數 `account_id`。
- 成功時 `data`：同 `GET /api/accounts` 的單一帳戶欄位。
- 最小範例：`{"code":200,"message":"查詢成功。","data":{"id":1,"name":"現金","kind":"cash","currency":"TWD","opening_balance":0,"statement_day":null,"payment_day":null}}`

#### `PATCH /api/accounts/{account_id}`

- 查詢參數：無。
- 請求欄位：路徑參數 `account_id`；`name` 可更新；`statement_day`、`payment_day` 可更新且可為 `null`。
- 成功時 `data`：同單一帳戶欄位。
- 最小範例：`{"code":200,"message":"帳戶更新成功。","data":{"id":1,"name":"現金","kind":"cash","currency":"TWD","opening_balance":0,"statement_day":null,"payment_day":null}}`

#### `GET /api/accounts/{account_id}/balance`

- 查詢參數：無。
- 請求欄位：路徑參數 `account_id`。
- 成功時 `data`：`account_id`、`currency`、`balance`、`balance_twd`。
- 最小範例：`{"code":200,"message":"帳戶餘額取得成功。","data":{"account_id":1,"currency":"TWD","balance":500,"balance_twd":500}}`

### 移轉

#### `GET /api/transfers`

- 查詢參數：無。
- 請求欄位：無。
- 成功時 `data`：移轉物件陣列；每項包含 `id`、`transferred_on`、`amount`、`currency`、`fx_rate_to_twd`、`from_account_id`、`to_account_id`、`note`、`created_at`、`updated_at`。
- 最小範例：`{"code":200,"message":"查詢成功。","data":[{"id":1,"transferred_on":"2026-08-02","amount":200,"currency":"TWD","fx_rate_to_twd":1,"from_account_id":1,"to_account_id":2,"note":null}]}`

#### `POST /api/transfers`

- 查詢參數：無。
- 請求欄位：`transferred_on`、`amount`、`currency`、`fx_rate_to_twd`、`from_account_id`、`to_account_id` 必填；`note` 可空。金額及匯率須大於零，兩個帳戶不可相同，幣別須符合帳戶。
- 成功時 `data`：同移轉物件欄位。
- 最小範例：`{"code":201,"message":"移轉新增成功。","data":{"id":1,"transferred_on":"2026-08-02","amount":200,"currency":"TWD","fx_rate_to_twd":1,"from_account_id":1,"to_account_id":2,"note":null}}`

#### `GET /api/transfers/{transfer_id}`

- 查詢參數：無。
- 請求欄位：路徑參數 `transfer_id`。
- 成功時 `data`：單一移轉物件，欄位同 `GET /api/transfers`。
- 最小範例：`{"code":200,"message":"查詢成功。","data":{"id":1,"transferred_on":"2026-08-02","amount":200,"currency":"TWD","fx_rate_to_twd":1,"from_account_id":1,"to_account_id":2,"note":null}}`

### 入帳

#### `GET /api/incomes`

- 查詢參數：`account_id`、`category_id`（正整數）；`date_from`、`date_to`（`YYYY-MM-DD`，含起訖日）。
- 請求欄位：無。
- 成功時 `data`：入帳物件陣列；每項包含 `id`、`received_on`、`amount`、`currency`、`fx_rate_to_twd`、`category_id`、`account_id`、`source`、`note`、`invoice_id`、`trade_id`、`created_at`、`updated_at`。
- 最小範例：`{"code":200,"message":"查詢成功。","data":[{"id":1,"received_on":"2026-11-05","amount":500,"currency":"TWD","fx_rate_to_twd":1,"category_id":1,"account_id":1,"source":"薪資","note":null,"invoice_id":null,"trade_id":null}]}`

#### `POST /api/incomes`

- 查詢參數：無。
- 請求欄位：`received_on`、`amount`、`currency`、`fx_rate_to_twd`、`category_id`、`account_id` 必填；`source`、`note` 至少一項有內容；`invoice_id`、`trade_id` 可空。金額及匯率須大於零，幣別須符合帳戶。
- 成功時 `data`：同入帳物件欄位。
- 最小範例：`{"code":201,"message":"入帳新增成功。","data":{"id":1,"received_on":"2026-11-05","amount":500,"currency":"TWD","fx_rate_to_twd":1,"category_id":1,"account_id":1,"source":"薪資","note":null,"invoice_id":null,"trade_id":null}}`

#### `GET /api/incomes/{income_id}`

- 查詢參數：無。
- 請求欄位：路徑參數 `income_id`。
- 成功時 `data`：單一入帳物件，欄位同 `GET /api/incomes`。
- 最小範例：`{"code":200,"message":"查詢成功。","data":{"id":1,"received_on":"2026-11-05","amount":500,"currency":"TWD","fx_rate_to_twd":1,"category_id":1,"account_id":1,"source":"薪資","note":null,"invoice_id":null,"trade_id":null}}`

#### `PATCH /api/incomes/{income_id}`

- 查詢參數：無。
- 請求欄位：路徑參數 `income_id`；交換格式未逐欄列出此 PATCH 可更新的欄位。
- 成功時 `data`：單一入帳物件，欄位同 `GET /api/incomes`。
- 最小範例：`{"code":200,"message":"入帳更新成功。","data":{"id":1,"received_on":"2026-11-05","amount":500,"currency":"TWD","fx_rate_to_twd":1,"category_id":1,"account_id":1,"source":"薪資","note":null,"invoice_id":null,"trade_id":null}}`

### 作廢

交換格式沒有定義獨立的作廢端點。交易欄位有可空的 `voided_at`，但沒有說明以哪個端點或請求欄位執行作廢；發票 `PATCH` 僅說明 `prize_status` 可設為 `void`。

### 發票

#### `POST /api/invoices`

- 查詢參數：無。
- 請求欄位：`number`、`issued_on`、`amount`、`kind` 必填；`currency` 可省略（預設 `TWD`）；`fx_rate_to_twd` 在幣別為 `TWD` 且未提供時使用 `1`，其他情況必須提供且大於零；`random_code`、`seller_name`、`seller_ban` 可空。號碼為兩碼大寫英文字母加八碼數字。
- 成功時 `data`：`id`、`number`、`issued_on`、`amount`、`kind`、`currency`、`fx_rate_to_twd`、`random_code`、`seller_name`、`seller_ban`、`prize_status`、`created_at`、`updated_at`；詳情另含 `items`、`expense_ids`。
- 最小範例：`{"code":201,"message":"發票新增成功。","data":{"id":1,"number":"AB12345678","issued_on":"2026-08-08","amount":70,"kind":"paper","currency":"TWD","fx_rate_to_twd":1,"random_code":null,"seller_name":null,"seller_ban":null,"prize_status":"unchecked"}}`

#### `GET /api/invoices`

- 查詢參數：`period_key`（雙月期，如 `2026-07`）；`prize_status`（`unchecked`、`lost`、`won`、`claimed`、`void`）。
- 請求欄位：無。
- 成功時 `data`：發票物件陣列；每項包含 `id`、`number`、`issued_on`、`amount`、`kind`、`currency`、`fx_rate_to_twd`、`random_code`、`seller_name`、`seller_ban`、`prize_status`、`created_at`、`updated_at`。交換格式將 `items`、`expense_ids` 標為詳情回應欄位。
- 最小範例：`{"code":200,"message":"發票資料取得成功。","data":[{"id":1,"number":"AB12345678","issued_on":"2026-08-08","amount":70,"kind":"paper","currency":"TWD","fx_rate_to_twd":1,"random_code":null,"seller_name":null,"seller_ban":null,"prize_status":"unchecked"}]}`

#### `GET /api/invoices/{invoice_id}`

- 查詢參數：無。
- 請求欄位：路徑參數 `invoice_id`。
- 成功時 `data`：發票基本欄位及詳情欄位 `items`、`expense_ids`；每個 `items` 包含 `id`、`invoice_id`、`name`、`quantity`、`unit_price`、`line_amount`、`created_at`、`updated_at`。
- 最小範例：`{"code":200,"message":"發票資料取得成功。","data":{"id":1,"number":"AB12345678","issued_on":"2026-08-08","amount":70,"kind":"paper","currency":"TWD","fx_rate_to_twd":1,"random_code":null,"seller_name":null,"seller_ban":null,"prize_status":"unchecked","items":[],"expense_ids":[]}}`

#### `PATCH /api/invoices/{invoice_id}`

- 查詢參數：無。
- 請求欄位：路徑參數 `invoice_id`；`number`、`issued_on`、`amount`、`kind` 不可改；`random_code`、`seller_name`、`seller_ban` 可改；`prize_status` 僅可設 `void`。
- 成功時 `data`：發票基本欄位；詳情回應可含 `items`、`expense_ids`。
- 最小範例：`{"code":200,"message":"發票資料更新成功。","data":{"id":1,"number":"AB12345678","issued_on":"2026-08-08","amount":70,"kind":"paper","currency":"TWD","fx_rate_to_twd":1,"random_code":null,"seller_name":null,"seller_ban":null,"prize_status":"void"}}`

### 發票品項

#### `POST /api/invoices/{invoice_id}/items`

- 查詢參數：無。
- 請求欄位：路徑參數 `invoice_id`；`name`、`quantity`、`unit_price`、`line_amount` 必填，數值均須大於零。
- 成功時 `data`：`id`、`invoice_id`、`name`、`quantity`、`unit_price`、`line_amount`、`created_at`、`updated_at`。
- 最小範例：`{"code":201,"message":"發票品項新增成功。","data":{"id":1,"invoice_id":1,"name":"午餐","quantity":1,"unit_price":70,"line_amount":70}}`

#### `GET /api/invoices/{invoice_id}/items`

- 查詢參數：無。
- 請求欄位：路徑參數 `invoice_id`。
- 成功時 `data`：發票品項物件陣列，欄位同 `POST /api/invoices/{invoice_id}/items` 成功資料。
- 最小範例：`{"code":200,"message":"查詢成功。","data":[{"id":1,"invoice_id":1,"name":"午餐","quantity":1,"unit_price":70,"line_amount":70}]}`

### 開獎期別

#### `POST /api/draw-periods`

- 查詢參數：無。
- 請求欄位：`period_key` 必填，格式為 `YYYY-01`、`YYYY-03`、`YYYY-05`、`YYYY-07`、`YYYY-09`、`YYYY-11`。
- 成功時 `data`：`id`、`period_key`。
- 最小範例：`{"code":201,"message":"開獎期別新增成功。","data":{"id":1,"period_key":"2026-07"}}`

### 獎項

#### `POST /api/draw-periods/{period_id}/prizes`

- 查詢參數：無。
- 請求欄位：路徑參數 `period_id`；`tier`、`matching_number`、`amount` 必填。`tier` 使用交換格式列出的獎項種類；`special`、`grand`、`first` 的號碼為八碼數字；`amount` 不可小於零。
- 成功時 `data`：`id`、`draw_period_id`、`tier`、`matching_number`、`amount`。
- 最小範例：`{"code":201,"message":"獎號新增成功。","data":{"id":1,"draw_period_id":1,"tier":"first","matching_number":"12345678","amount":500}}`

### 對獎

#### `POST /api/draw-periods/{period_id}/check`

- 查詢參數：無。
- 請求欄位：路徑參數 `period_id`；無 body 欄位。
- 成功時 `data`：`checked_count`、`won_count`。
- 最小範例：`{"code":200,"message":"本期發票對獎完成。","data":{"checked_count":1,"won_count":1}}`

### 中獎入帳

#### `POST /api/invoices/{invoice_id}/prize-income`

- 查詢參數：無。
- 請求欄位：路徑參數 `invoice_id`；`category_id`、`account_id` 必填。
- 成功時 `data`：`invoice`（發票欄位，不含品項清單）及 `income`（入帳物件欄位）。
- 最小範例：`{"code":201,"message":"中獎入帳新增成功。","data":{"invoice":{"id":1,"number":"AB12345678","issued_on":"2026-08-08","amount":70,"kind":"paper","currency":"TWD","fx_rate_to_twd":1,"random_code":null,"seller_name":null,"seller_ban":null,"prize_status":"claimed"},"income":{"id":2,"received_on":"2026-11-14","amount":500,"currency":"TWD","fx_rate_to_twd":1,"category_id":1,"account_id":1,"source":"統一發票中獎","note":null,"invoice_id":1,"trade_id":null}}}`

### 月合計

#### `GET /api/summary`

- 查詢參數：`month` 必填，格式 `YYYY-MM`。
- 請求欄位：無。
- 成功時 `data`：`month`、`income_twd`、`expense_twd`；無資料時合計為 `0`。投資交易不直接計入入帳或花費。
- 最小範例：`{"code":200,"message":"月收支摘要取得成功。","data":{"month":"2026-08","income_twd":0,"expense_twd":70}}`

## 兩份文件的差異

| 欄位／範圍 | 交換格式 | 資料表設計 |
|---|---|---|
| 帳戶類型 | `accounts.kind`；值為 `cash`、`bank`、`credit_card`、`broker`。 | `accounts.account_type`；值為 `cash`、`bank`、`credit_card`、`brokerage_cash`。欄位名與券商帳戶值不同。 |
| 帳戶期初金額 | 帳戶物件含 `opening_balance`，未列獨立資源。 | 另有 `opening_balances.amount`、`currency`、`fx_rate`、`effective_at`，且每帳戶最多一筆；欄位組成不同。 |
| 帳戶結帳／繳款日 | `statement_day`、`payment_day` 可空。 | `accounts` 未列這兩欄。 |
| 入帳日期 | `incomes.received_on`，日期字串。 | `income_entries.received_at`，必填時間戳記。欄位名及日期／時間粒度不同。 |
| 入帳匯率 | `fx_rate_to_twd`。 | `fx_rate`。欄位名不同。資料表另明訂 TWD 匯率須為 1；交換格式只說匯率大於零。 |
| 入帳來源／備註 | 有 `source`、`note`，且至少一項有內容。 | `income_entries` 未列這兩欄，也未列至少一項有內容的限制。 |
| 花費日期 | `expenses.spent_on`，日期字串。 | `expense_entries.spent_at`，必填時間戳記；欄位名及粒度不同。 |
| 花費結算時間 | `settled_on` 可空。 | `posted_at` 必填，表示反映到帳戶的時間；名稱、意義及可空性不同。 |
| 花費商家／備註 | `merchant`、`note` 至少一項有內容。 | `expense_entries` 只列可空 `note`，未列 `merchant` 或至少一項有內容的限制。 |
| 花費與發票關聯 | 花費物件含可空 `invoice_id`。 | 以 `invoice_expenses` 關聯表連結發票與花費；不是花費表上的 `invoice_id`。 |
| 移轉金額與匯率 | 一組 `amount`、`currency`、`fx_rate_to_twd`。 | 分別保存轉出與轉入的 `from_amount`／`to_amount`、幣別及匯率；交換格式未描述不同幣別兩端各自金額。 |
| 移轉日期 | `transferred_on`，日期字串。 | `transferred_at`，必填時間戳記；欄位名及粒度不同。 |
| 發票號碼 | `number`。 | `invoice_number`。欄位名不同；交換格式稱唯一，資料表唯一性是 `invoice_period_start` 與 `invoice_number` 的組合。 |
| 發票開立日期／期別 | `issued_on` 日期；查詢 `period_key`。 | `issued_at` 時間戳記及必填 `invoice_period_start` 日期。欄位名及粒度不同。 |
| 發票金額 | `amount` 必須大於零。 | `total_amount` 不得為負，允許零。欄位名及下限約束不同。 |
| 發票種類 | `kind` 為 `paper` 或 `electronic`。 | `invoices` 未列 `kind`。 |
| 發票匯率 | `fx_rate_to_twd`；TWD 可省略並預設 1。 | `fx_rate` 必填，且依共通規則 TWD 必須等於 1。欄位名及輸入省略規則不同。 |
| 發票其他欄位 | 有 `random_code`、`seller_ban`、`prize_status`；`seller_name` 可空。 | 未列 `random_code`、`seller_ban`、`prize_status`；有可空 `seller_name`，另有可空 `note`。 |
| 發票品項名稱 | `invoice_items.name`。 | `invoice_items.item_name`。欄位名不同。 |
| 品項價格限制 | `quantity`、`unit_price`、`line_amount` 均須大於零。 | `quantity` 須大於零；`unit_price`、`line_amount` 不得為負，允許零。約束不同。 |
| 開獎期別／獎項 | `draw_periods.period_key`、`draw_prizes.tier`、`matching_number`、`amount`。 | 沒有 `draw_periods` 或 `draw_prizes` 表；僅有 `invoice_prize_rules`，欄位為 `invoice_period_start`、`prize_type`、`winning_suffix`、`match_digits`、`award_amount`。資料模型與欄位不同。 |
| 獎號規則 | 特別獎、特獎、頭獎號碼須為八碼數字。 | `winning_suffix` 為一至八碼數字，並以 `match_digits` 記錄位數；規則表示不同。 |
| 獎金 | `amount` 不可小於零。 | `award_amount` 台幣金額且不得為負；符號範圍相同，欄位名不同。 |
| 健康檢查、持有量、作廢、報價 | 交換格式沒有健康檢查、持有量、獨立作廢、抓取報價、報價清單或最新報價端點規格。 | 資料表設計沒有健康檢查、持有量 API、作廢 API 或報價表；並明列不建即時股價／行情表。持有股數僅描述為由交易計算。 |

其他已對照欄位若未列於此表，表示兩份文件未見直接的欄位名稱、可空性或約束衝突；API 欄位與資料表欄位未能一對一對應者已明確列出。

因此目前缺少的端點規格為：健康檢查、持有量、獨立作廢、抓取台股報價、報價清單及單筆最新報價。交換格式未提供這些端點的 HTTP 方法、路徑、請求或回應欄位，前端串接前需補齊規格。
